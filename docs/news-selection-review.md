# Проверка GildraNews — 11 октября 2026

Проверены работающий контейнер `newsbot`, последние записи базы в режиме только чтения,
ограниченный хвост логов и текущая цепочка отбора. Контейнер работал и имел статус healthy.
Изменения подготовлены локально; рабочий контейнер во время проверки не обновлялся.

## Наблюдения

В таблице `runs` за последние 24 часа: 48 прогонов, 8 полученных материалов,
2 отобранных и опубликованных, один прогон с ошибкой. Эти числа относятся к журналу
прогонов и не являются полной оценкой всех ручных запросов и повторных попыток.

Последние опубликованные тексты содержат практическую конкретику: условия получения
награды, ограничения по расе и региону, отличие визуального сбоя от реального урона,
отметку тестового статуса PTR. Основная подача уже полезна игроку.

В просмотренном хвосте из 300 строк логов за сутки: 22 запроса редакторского исправления,
8 ошибок AI-анализа и ни одной ошибки отправки RSS-поста в Telegram. Семь ошибок
AI относились к проверке ветки игры, одна — к сохранности текста при исправлении.
Это счётчики строк ограниченного хвоста, а не число уникальных новостей за сутки.

Два сохранённых задания с ошибкой проверки ветки касались WoW: Forever. Проверка
требовала название этой ветки, а инструкция редакторского исправления описывала только
Retail и Classic. В исходной цепочке также допускалось продолжение генерации после
удаления всех неподтверждённых цитат из карты фактов.

## Подготовленные изменения

- Явная новостная ценность: важный анонс, практическое изменение, подтверждённая находка
  или отсутствие новизны. Последний вариант не доходит до написания поста.
- Конкретная польза игроку важнее громкости заголовка и популярности источника.
  Повторные превью, рекламные подборки и перепечатки без новых фактов отсеиваются;
  официальный анонс дополнения и новая награда с условиями получения сохраняют ценность.
- Основная цитата обязательна и проверяется по исходнику. Выдуманная основная цитата,
  пустая карта фактов и цитата из пробелов блокируют генерацию.
- Исправление текста получает ветку, статус события и проверенные цитаты.
  Для Forever добавлена явная инструкция и регрессионный тест.
- Sonnet 5.5 подключён через официальный Anthropic Messages API. Обрывы, отказы и
  неверные ответы не принимаются за готовый текст; временные сбои имеют ограниченные повторы.
- Для сайта готовится самостоятельная статья из сохранённого исходника, с отдельной
  проверкой после редактуры. [Контракт API](news-api.md) описывает поля и подключение.

Сверены обновлённые
[EditorTeam](https://github.com/Manacost-Labs/ManacostTeam/blob/main/editor/MIGRATION.md) и
[ResearchTeam](https://github.com/Manacost-Labs/ManacostTeam/tree/main/research).
Контракт `/v2/edit` совместим с текущим клиентом. Принципы ResearchTeam применены к
сохранению источника, цитат и статуса информации; отдельный deep-research не запускался.

## Проверка и оставшиеся условия

308 тестов проходят; Ruff, проверка diff и актуальности lock-файла проходят.
Первоначально ключ Anthropic отсутствовал. После его подключения официальный API
подтвердил доступ к `claude-sonnet-5-5`. Живая проверка на сохранённом материале о плаще
паладинов прошла без публикации в Telegram: новость принята с веткой `forever`,
статья для сайта содержит 2 191 символ и 13 проверенных цитат, итоговая проверка пройдена.
Ключ и отдельный токен API сохранены в игнорируемых Git файлах с правами `0600`;
конфигурация подготовлена. Пользователь разрешил деплой, обновление запущено 11 октября.
Бот и API имеют статус healthy, база мигрирована с версии 3 на 4, прежние записи сохранены.
Перед миграцией сохранена согласованная резервная копия базы и прежний Docker-образ.

Проверена полная рабочая цепочка на новой публикации о секретном боссе в бета-версии
WoW: Forever: Telegram-текст — 498 символов, статья сайта — 1 579 символов,
8 сохранённых цитат. API списка, отдельной статьи и курсора возвращает ожидаемые ответы;
запрос без токена получает 401. API слушает `127.0.0.1:8088` на сервере.
В просмотренных стартовых логах нет ошибок AI, генерации сайта или traceback;
оба контейнера работают без перезапусков.
После активации нужно оценить реальные принятия/отказы и исправления на ограниченной
выборке: тесты подтверждают работу проверок, но не измеряют качество модельного отбора.

## Исправление языка и дальнейшая редактура

В первой статье сайта осталось слишком много английских названий: генератор получил
только словарь классов, а отдельная проверка оценивала факты без проверки языка.
Теперь все публичные поля проверяются общими правилами непереведённых терминов и клише.
Названия локаций, предметов и боссов передаются по-русски без английских дублей;
новый вариант имени не выдаётся за официальную локализацию. Служебные цитаты сохраняются
дословно. Проверяются повтор лида, согласование и последовательность названий.

Добавлены ограниченные исправления по найденным нарушениям и замечаниям итоговой
проверки, с повторной проверкой полного текста, чисел и цитат. При сохраняющихся ошибках
статья не выпускается. Для отбора поле новостной ценности обязательно: пропущенная
оценка больше не позволяет молча пройти к черновику. Повторный сюжет должен иметь
существенный новый факт или изменение статуса события; новая дата публикации сама
по себе не делает событие новым.

319 тестов проходят; Ruff, проверка diff, lock-файлов и конфигурации Compose проходят.
Живая проверка обнаружила повтор лида, ошибку согласования и непоследовательное имя
босса; исправление по этим замечаниям прошло повторную проверку. Статья №1 заменена
проверенным русским текстом, 1 326 символов в body. Перед заменой сохранена резервная
копия SQLite. Обновлённый образ запущен: бот и API healthy, без перезапусков; API статьи
возвращает 200 и исправленный текст, запрос списка без токена — 401. Прежний образ сохранён.
