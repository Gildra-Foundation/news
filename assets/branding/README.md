# Источники фирменных игровых значков

- `the-last-titan.webp` — прозрачный логотип дополнения из Warcraft Wiki,
  предоставленный владельцем канала. Пропорции сохранены; в проекте хранится
  нормализованная версия 100×100 для Telegram Custom Emoji.
- `wow-forever.webp` — прозрачный логотип WoW: Forever, предоставленный
  владельцем канала. Лишние прозрачные поля удалены, пропорции сохранены;
  в проекте хранится нормализованная версия 100×100 для Telegram Custom Emoji.
